## R Conventions

- Use `fixest` for all fixed-effect regressions (LaTeX export via `etable`).
- Use `tidyverse` + `data.table` for data wrangling; prefer `data.table` for large panels.
- Use `modelsummary` or `fixest::etable` for LaTeX table output.

---

## LaTeX Conventions

- Tables generated by `etable()` or `modelsummary()` — do **not** hand-edit `.tex` table files.
- Use `\input{../output/tables/tab_baseline.tex}` in `main.tex`.
- Figures: `\includegraphics[width=\linewidth]{../output/figures/fig_main.pdf}`.

---

## Claude Instructions

When helping with this project:

1. **Do not** overwrite files in `data/raw/`
2. **LaTeX:** Output should be publication-ready. Use `booktabs`, avoid vertical lines in tables, follow AER/JF style.
